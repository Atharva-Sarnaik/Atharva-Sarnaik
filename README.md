## Things I've built

### 🎙️ Koe Scroll &nbsp;·&nbsp; [repo](https://github.com/Atharva-Sarnaik/Koe-Scroll) &nbsp;·&nbsp; [live](https://koe-scroll.vercel.app)
> Manga that speaks back.

A cross-platform AI manga dubbing system. Upload a manga page — Gemini 2.5 Flash reads the panels in the correct Japanese reading order, extracts dialogue with character context, and ElevenLabs voices each character distinctly. Built for the Dreamflow Buildathon.

`TypeScript` `React Native (Expo)` `Gemini 2.5 Flash` `ElevenLabs` `Supabase` `React + Vite`

Key engineering decisions:
- Custom `ScriptPostProcessor` — geometric clustering to enforce right-to-left, top-to-bottom panel order
- Cross-platform sync: pause on web, resume on mobile instantly
- Voice Lab with per-character speed, stability & pronunciation overrides
